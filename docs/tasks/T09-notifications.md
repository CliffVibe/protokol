# T09. Уведомления и объявления

## Сделать
- `/notifications`: вкладки «Все / Объявления / Дедлайны / Заявки / Расписание», непрочитанные выделены, «Отметить всё прочитанным».
- Бейдж в навигации — количество непрочитанных.
- Сотрудник: `/staff/announcements` — создать объявление для факультетов/курсов/групп, закрепить. Публикация создаёт уведомления адресатам.
- Изменение пары сотрудником (простая форма переноса) → уведомление группе.
- Markdown в объявлениях — через санитайзер.

- `Notification.link`, `Deadline.link` (из security-ревью T02): в zod — только относительный путь `/^\/(?!\/)/`, иначе `javascript:` и открытый редирект в `href`.

## Приёмка
- [ ] Объявление для МЭО не видит Алиса (ФМО)
- [ ] Перенос пары появляется у студентов группы в уведомлениях и на главной
