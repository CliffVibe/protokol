# T05. Главная «Сейчас»

**Цель:** за 0 касаний ответить «что мне сейчас важно». Сценарий 1 из концепции.

## Состав (сверху вниз, по срочности)
1. Приветствие + дата («Доброе утро, Алиса · чт, 5 нояб.»).
2. `NowCard`: текущая или ближайшая пара; «через 25 мин» / «идёт, до конца 40 мин»; перенос подсвечен. Если пар сегодня нет — следующая учебная день.
3. «Изменения» — переносы/отмены на сегодня-завтра (если есть).
4. «Скоро» — ближайшие 3 дедлайна и экзамены.
5. «Мои заявки» — активные, со статусом; «Готова — заберите» выделено.
6. «Объявления» — закреплённые + последнее непрочитанное.
7. Мини-сводка учёбы: средний рейтинг, `ScholarshipBadge`.

## Тех
- Server Component; `services/now.ts` собирает всё одной функцией из репозиториев (параллельно, `Promise.all`).
- «Через N минут» — клиентский компонент с обновлением раз в минуту.

## Из внешней оценки дизайна 06.11 (`docs/process/design-review-06-11.md`)
- Десктоп ≥ 1024: правая колонка «Сегодня» (ближайшая пара, изменения, дедлайны), как обещает 04-design, — без пустой половины экрана.
- Одна заливная главная кнопка на экран; остальные действия — контурные или текстовые.
- Маленький знак в шапке — со штемпельным кольцом, а не залитый круг «буква в кружке».

## Приёмка
- [ ] У Алисы видны перенос и готовая заявка; у Веры — аккуратные пустые состояния
- [ ] Каждый блок ведёт в свой раздел за 1 касание
- [ ] LCP < 2.5 с на эмуляции мобильного (Lighthouse)
