# T10. Мастер «Зачем нужна справка?», PDF и QR-проверка

> Перед началом человек включает security-guidance на время задачи (см. `docs/07-tooling.md`).

## Сделать
- `PurposePicker` первым шагом `/requests/new`: цель → подходящие типы (по `purposeTags`) → язык → форма. Ссылка «Я знаю, какая справка нужна» → полный каталог.
- При статусе READY генерируется PDF (`@react-pdf/renderer`): вымышленная шапка «Протокол · концепт», данные, QR на `/verify/<token>`, водяной знак «ОБРАЗЕЦ · КОНЦЕПТ ДЛЯ КОНКУРСА».
- Кириллица: зарегистрировать TTF (Inter, OFL) через `Font.register`; встроенные шрифты react-pdf кириллицу не рисуют. Юнит-тест: в тексте PDF есть «Справка».
- Скачивание PDF — только владелец (проверка владения на сервере).
- `/verify/[token]`: «Действительна / Отозвана / Не найдена», тип, дата, инициалы. Сотрудник может отозвать.
