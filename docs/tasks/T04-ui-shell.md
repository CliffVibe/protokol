# T04. Каркас UI и дизайн-система

**Цель:** все экраны будут собираться из одних кирпичиков. Перечитай `docs/04-design.md`.

## Сделать
- Токены в `globals.css` (светлая + тёмная, `prefers-color-scheme` + переключатель).
- Layout студента: нижняя навигация (мобильный) / боковая (≥1024), бейдж уведомлений, футер с `ConceptBanner`.
- Layout сотрудника — проще, десктоп-первый, но рабочий на телефоне.
- Компоненты: `StatusChip`, `EmptyState`, `ErrorState`, skeleton-набор, `PageHeader`, `ConceptBanner`, логотип-печать (SVG, своё).
- Страница `/dev/ui` (только в dev) — витрина компонентов во всех состояниях (скриншоты для отчёта).

## Приёмка
- [ ] Навигация доступна с клавиатуры, цели ≥ 44px
- [ ] Контраст ≥ 4.5:1 в обеих темах (проверка `ux-reviewer`)
- [ ] Нет горизонтального скролла на 360px
