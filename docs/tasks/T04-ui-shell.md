**Цель:** все экраны будут собираться из одних кирпичиков. Перечитай `docs/04-design.md`.

## Сделать
- Токены в `globals.css` (светлая + тёмная, `prefers-color-scheme` + переключатель).
- Layout студента: нижняя навигация (мобильный) / боковая (≥1024), бейдж уведомлений, футер с `ConceptBanner`.
- Layout сотрудника — проще, десктоп-первый, но рабочий на телефоне.
- Компоненты: `StatusChip`, `EmptyState`, `ErrorState`, skeleton-набор, `PageHeader`, `ConceptBanner`, логотип-печать (SVG, своё).
- Страница `/dev/ui` (только в dev) — витрина компонентов во всех состояниях (скриншоты для отчёта).

## Хвосты из UX-ревью T01 (05.11)
- `--warn` светлый `#B26A00` как текст не проходит 4.5:1 (3.89 на bg) — решение человека: затемнить токен (предложено `#965900`) или запретить `--warn` для текста. Нужно до T05 («подсвеченный перенос»).
- Пары на `--brand-soft`: `--ink-muted` (4.29) и светлый `--ok` (4.28) — не использовать для текста на brand-soft или затемнить.
- `button.tsx` (shadcn): размеры по умолчанию до 44px (`h-11`, `icon` → `size-11`); `ring-ring/50` → `ring-ring`; `transition-all`/`active:translate-y-px` → `transition-colors duration-150 ease-out` («ничего не прыгает»).
- Шкала типографики в `@theme` в rem (`--text-h1: 1.75rem` …), чтобы масштаб 200% не ломал иерархию.
- `meta theme-color` синхронизировать с переключателем темы (сейчас дублирует `--bg` по системной теме).
- Значок сайта `src/app/icon.svg` — монограмма-печать в `--seal` (сейчас `/favicon.ico` → 404).
