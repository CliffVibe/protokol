# T12. ИИ-помощник деканата (SHOULD — первым на этапе 4, сразу после ядра)

> Минимум, который не режем: FAQ без ИИ + GigaChat + кнопки-действия. Расширения для сотрудника — если есть время.

> Перед началом человек включает security-guidance на время задачи (см. `docs/07-tooling.md`).

Перечитай раздел «ИИ-помощник» в `03-architecture.md` и S8 в `05-security.md`.

## Сделать
- `content/faq/*.md` — вымышленная база ответов (10–15 статей: как перевестись, академ, пересдача, справки, стажировки).
- `services/ai/provider.ts` — интерфейс; реализации `gigachat` и `faqOnly` (поиск по FAQ без ИИ). Выбор по наличию env.
- `services/ai/context.ts` — контекст **текущего** студента: пары на 7 дней, сводка оценок, активные заявки.
- `/api/assistant` — стрим; лимит 20/час; ответ = текст + `actions[]` (whitelist маршрутов).
- `/assistant` — чат, подсказки-чипы («Когда следующий экзамен?», «Справка для военкомата»), кнопки действий. Пометка «Ответы ИИ могут быть неточны».
- TLS GigaChat: «Russian Trusted Root CA» в образе + `NODE_EXTRA_CA_CERTS` (проверку TLS не отключать).
- Расширения для сотрудника: «Черновик ответа» к заявке (сотрудник правит и отправляет сам) и авто-категория входящей заявки. Модель ничего не меняет сама.
