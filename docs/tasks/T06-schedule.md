# T06. Расписание

## Сделать
- `/schedule`: переключатель «Сегодня / Неделя», свайп/стрелки по неделям, `?week=YYYY-Www`.
- Основная группа + языковые группы в одной ленте; бейдж языка.
- Изменения: перенос (было/стало), отмена (зачёркнуто), смена аудитории/преподавателя — иконка + цвет + текст.
- Подсказка «Переход между корпусами» если подряд пары в разных зданиях.
- Тап по паре → лист с деталями (аудитория, корпус, преподаватель, тип, заметка об изменении).
- Пустой день: «Пар нет».
