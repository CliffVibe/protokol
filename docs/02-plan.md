## Порядок работы над каждой задачей (цикл)

1. Человек: `/next-task` → Claude читает задачу, задаёт вопросы, предлагает план (plan mode).
2. Человек одобряет план (скриншот плана → `docs/process/screenshots/`).
3. Claude реализует, гоняет тесты.
4. Claude вызывает субагентов-ревьюеров (`security-reviewer`, `ux-reviewer`, `mobile-qa`) по необходимости.
5. Человек проверяет руками на телефоне (это «ручной этап» для отчёта).
6. `/log` → запись в журнал. Коммит. Деплой (`/deploy` или вручную).
