### Замечания (информационные, правок не требуют)
- **Низкая / информационно.** `src/server/repos/demo.ts:20` — `resetDemoData(ctx)` принимает `ctx`, но не использует (кулдаун — глобальный на процесс). Не уязвимость: роль (`requireStaff`) и `DEMO_MODE=1` проверяются в `resetDemoAction` (`src/server/actions/staff.ts:92-95`) до вызова. Параметр оставлен ради единого вида «функция репозитория принимает ctx». При желании — убрать неиспользуемый параметр.
- **Информационно.** `certs/russian_trusted_root_ca.pem` в git — ПУБЛИЧНЫЙ корневой сертификат Минцифры для TLS к GigaChat, не секрет (S4 не нарушается).
- **Информационно.** В `src/app/api/assistant/route.ts` guard `requireStudent()` — первой строкой, а проверки Origin/Content-Type/лимита идут до парсинга тела — CSRF/DoS защита выстроена правильно.

### Проверено, без проблем (кратко; подробности и привязка к тестам — в `red-team-T13.md`)

- **S1 изоляция данных — держится.** `db.*` только в `src/server/repos/*` (16 совпадений grep). Каждая «пользовательская» функция фильтрует по `ctx.studentId` / `ctx.facultyIds`, включая мутации (`findFirst`+`updateMany`, `count===1`). 4 исключения из правила ctx (`system`, `auth`, `verify`, `calendar`) проверены индивидуально — лишнего наружу не уходит. ID владельца нигде не берётся из URL/формы/query.
- **S1 guards — держится.** `requireStudent/requireStaff` в каждой page/Server Action/route первой инструкцией; тест-страж `guards.test.ts` разбирает AST и падает при нарушении.
- **S2 пароли — держится.** argon2id (m=19 МиБ, t=2), единая ошибка, фиктивный хеш для timing, блокировка 5/15мин→5мин (`reserveAttempt` атомарно), пароль >128 не хешируется.
- **S3 сессии — держится.** Токен 32 байта, в БД `sha256`, `__Host-session` HttpOnly/Secure/SameSite=Lax/Path=/, выход и «на всех устройствах» удаляют из БД. (Смена пароля студентом в прототипе отсутствует — пункт неприменим.)
- **S4 секреты — держится.** `NEXT_PUBLIC_` для ключей — 0. `GIGACHAT_AUTH_KEY`/`DATABASE_URL` только на сервере. `.env*` в `.gitignore`, трекается только `.env.example`.
- **S5 ввод/вывод — держится.** Весь ввод через zod; вставок сырого HTML через опасный проп React (`dangerously`-проп) в коде нет (и блокируется `guard.mjs`); Markdown — дерево без HTML-строк; ссылки через `safeLink`/`safeExternalLink`.
- **S6 заголовки/CSP — держится.** CSP с nonce без unsafe-inline, `frame-ancestors none`, nosniff, Referrer-Policy, X-Frame-Options DENY, HSTS, `poweredByHeader:false`.
- **S7 публичные точки — держится.** `/verify` токен 128 бит, только разрешённые поля; `/api/calendar` токен 256 бит, только пары; битый токен → 404 без тела; `ics.ts` экранирует спецсимволы (нет инъекции в VEVENT).
- **S8 ИИ-помощник — держится.** В промпт — только данные текущего студента из ctx; системный промпт не раскрывается; действия только whitelist; лимиты 20/час (БД) + 60/мин (память); ответ не исполняется. **SSRF нет** — URL GigaChat хардкод, TLS не отключается.

### Доп. векторы (вне явных S1–S9) — чисто
IDOR через Server Actions (`cancelRequest`/`changeStatus`/`revokeDocument`/`rescheduleLesson`/`setPinned`/`markRead` — владелец/факультет + `count===1`); открытый редирект (все `redirect()` на фиксированные/валидированные относительные пути); `$queryRaw` инъекции (`reserveAttempt`, `reserveAiCall` — теговые шаблоны Prisma, параметризация).

**Вывод субагента:** нарушений инвариантов не обнаружено; защита подтверждается кодом и e2e-тестами.
