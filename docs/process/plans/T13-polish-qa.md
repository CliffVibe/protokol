## Часть А. Хвосты, 404/500, e2e-база

- `playwright.config.ts`: e2e-адрес БД выводится из `DATABASE_URL` заменой имени базы на `protokol_e2e` (`.env` не меняем) и кладётся в `process.env.DATABASE_URL` до старта webServer → сервер и хелперы (`tests/e2e/helpers/db.ts`, `temp-student.ts`, тест 6 в `security.spec.ts`) смотрят в неё. Тест 6 — на `localDatabaseUrl()` (сейчас без защиты хоста).
- Порт e2e по умолчанию → `3100`: `reuseExistingServer` не подхватит демо-сервер человека на 3000 (иначе тесты молча пошли бы в демо-базу).
- Новый `tests/e2e/global-setup.ts`: только локальный хост (`localDatabaseUrl`) → `CREATE DATABASE protokol_e2e`, если нет → `prisma migrate deploy` → сид (`pnpm db:seed`, пароли — `SEED_PASSWORD_*` из env процесса). Сид свежий на каждом прогоне — уходят 4 e2e, падавшие от устаревшего сида. Файл — в исключения eslint.
- Новая база = третья для `prisma migrate deploy`; global-setup применяет миграции сам. Записать в `03-architecture.md` (раздел тестов) и в `CLAUDE.md` → «Команды» строкой.

**А2. e2e «в HTML нет секретных полей»** (`tests/e2e/security.spec.ts`): HTML и RSC-ответ `/staff`, `/staff/requests/<n>` (Ирина), `/requests`, `/requests/<n>` (Алиса), `/verify/<token>` (аноним) не содержат `$argon2id$`, `recordBookNo`, `calendarToken` и **значений** (зачётка и токен календаря Алисы, префикс хеша — из БД через `withDb`). `/profile` не входит: токен там показан намеренно.

**А3. 404/500 в стиле приложения**
- `src/app/not-found.tsx`: шапка `BrandMark`, тихая строка «Ошибка 404», `h1` «Такой страницы нет», «Возможно, ссылка устарела или в адресе опечатка», ссылка «На главную»; `SiteFooter`. Метафора бланка — сноска с чертой, без новых цветов.

**А4. Хвосты ревью**
- Нижняя панель при 200% (`src/components/nav/bottom-nav.tsx`): контейнерный запрос в `em` — когда панель уже порога (крупный текст), подписи уходят в `sr-only`, остаются иконки (имя ссылки — та же подпись). - `PageHeader` (`src/components/page-header.tsx:140`): `hyphens-auto` у `h1` (на `<html lang="ru">`), `break-words` у описания; проверить все экраны при 200%.

- Пересдача из долга: новый тип `retake` «Заявление на пересдачу» в `prisma/seed-data.ts` (поле «Дисциплина», «Комментарий» необязательно; на «Готова» документ — направление на пересдачу, `TITLE_EN` в `src/lib/certificate-en.ts`). Мастер (`src/lib/request-wizard.ts`): параметр `discipline` (zod, формат id) → страница ищет дисциплину **через repo с ctx** (только своя) и подставляет название в поле; чужой/битый id — игнор. - Подсказки полей: в схему поля (`src/server/services/request-rules.ts`) — необязательный `hint` (≤ 120); `request-form.tsx` передаёт его в `FormField hint` (уже есть `aria-describedby`). Визовая: «Страна» — «Например: Франция», «Даты поездки» — «Например: 12.01–26.01.2027». Английский по умолчанию: при `type=embassy` без `purpose` — тоже рекомендовать английский (сейчас только с `purpose=visa`).
- Проверки 200%: общий хелпер ждёт `document.fonts.ready` перед замером ширины.
- Сид меняется (новый тип) → демо-базу человека обновить `pnpm db:reset-demo` (полный пересев; да дано 09.11) после коммита; e2e-база сеется сама.

## Часть Б. Качество

- **chrome-devtools-mcp** (решение человека 09.11): `pnpm exec playwright install chromium` (размер назову по факту, папка `%LOCALAPPDATA%\ms-playwright\chromium-*`) → `claude mcp add chrome-devtools -s local -- npx -y chrome-devtools-mcp@1.12.0 --isolated --headless --no-usage-statistics --no-performance-crux --executablePath <chromium>`.
