## J. «Вам положено» — деканат предлагает сам
- **Правило (вымышленное, с пометкой на экране):** повышенная стипендия — если `averageRating ≥ 80`, `debts === 0` и `scholarship.kept` (`StudySummary` из `src/server/services/academics.ts` → `summarizeStudy`). Алиса (82, без долгов) — проходит; Тимур — нет. Чистая функция `offersFor(study, existing, dismissed)` в новом `src/server/services/offers.ts` — расширяемо (массив правил), юнит-тесты.
- **Данные (одна миграция `20261111…_offers_ratings`):**
  - новый тип справки `scholarship_up` «Заявление на повышенную стипендию» (сид; поле `comment` необязательное), `purposeTags: ["other"]`, slaDays 5;
  - `Request.offered Boolean @default(false)` — «предложено деканатом»;
  - `OfferDismissal { studentId, code, semester, createdAt; @@unique([studentId, code, semester]) }` — «Не сейчас» прячет предложение до следующего семестра.
- **Предложение не показываем**, если у студента уже есть заявка этого типа не в статусе CANCELLED/REJECTED или оно отклонено в этом семестре.
- **«Сейчас»:** блок «Деканат предлагает» первым в ленте (над «Изменениями»), язык статусов Б′: черта `--brand`, значок `Sparkles`/`HandCoins`, «Вам положено: повышенная академическая стипендия», почему («средний рейтинг 82 из 100, долгов нет»), сноска «Правило вымышленное — для демо», заливная «Подать заявление» (единственная на экране) + ghost «Не сейчас».
- **Действия** `src/server/actions/offers.ts`: `acceptOfferAction` / `dismissOfferAction` — `requireStudent()` первой строкой, zod (`code` из списка правил, `clientKey` uuid), **условие пересчитывается на сервере** (кнопка — не доказательство), заявка через существующий `createRequest` (`src/server/repos/requests.ts`, расширить параметром `offered`) → редирект на заявку; `revalidatePath("/")`.
- **Сотрудник:** в очереди и карточке — чип «Предложено деканатом» (`QueueRow`, `src/components/staff/queue-row.tsx`); студенту в таймлайне — «Деканат предложил, вы подтвердили».

## K. Оценка заявки + «Вы сказали — мы сделали»
- **Данные (та же миграция):** `Request.rating Int?` (1–5), `ratingComment String?` (≤ 300), `ratedAt DateTime?`; `Announcement.youSaid Boolean @default(false)`.
- **Студент** (`src/app/(student)/requests/[number]/page.tsx`, новая секция между статусом и таймлайном): на READY/ISSUED — «Как вам работа деканата?» пять кнопок 1–5 (радиогруппа, цели 44px), комментарий необязательно, «Отправить оценку»; после — «Спасибо! Ваша оценка: 5 из 5» (оценка одна, без правки). Действие `rateRequestAction` (`src/server/actions/requests.ts`): `requireStudent`, zod (`requestNumberSchema`, `rating` 1–5, `comment` ≤ 300), репозиторий обновляет только `{number, studentId: ctx.studentId, status in [READY, ISSUED], rating: null}` → иначе 404/конфликт.
- **Сотрудник** (`src/app/(staff)/staff/(queue)/page.tsx`): секция «Что говорят студенты» над списком — по типам справок своих факультетов: средняя оценка, число оценок, 2–3 последних комментария **без имён** (репо `ratingsSummary(ctx)` в `src/server/repos/staff-requests.ts`, фильтр `ofMyFaculties`), ссылка «Ответить объявлением «Вы сказали — мы сделали»».
- **Объявления:** в форме сотрудника (`src/components/staff/announcement-form.tsx`) — галочка «Ответ на отзывы студентов» → `youSaid`; на доске и в «Сейчас» — пометка «Вы сказали — мы сделали» (значок + текст).
- **Сид:** 4–5 исторических ISSUED-заявок с оценками и комментариями у фоновых студентов ФМО/МЭО (не у Алисы и не у Веры — тесты сида), одно объявление `youSaid` («Вы просили — продлили приём справок до 19:00 по четвергам»).

## N. Свободные аудитории в окно между парами
- **Окно** — промежуток ≥ 60 мин между соседними (не отменёнными) парами одного дня; считается рядом с `buildTransitions` в `src/server/services/schedule.ts`.
- **Новый репозиторий** `src/server/repos/rooms.ts`: `roomsOfBuilding(building, from, to)` и `busyRooms(building, from, to)` — **только строки аудиторий**, без групп, предметов и людей. Это исключение из правила «repos с ctx» (как `system.ts`/`verify.ts`) — функции принимают `StudentCtx` ради единообразия, но данных пользователей не трогают; записать в `CLAUDE.md` → «Структура» и в `03-architecture.md`.
- **Свободна** = аудитория встречалась в расписании корпуса на этой неделе и не занята в окно. Показываем до 5 + «и ещё N», оговорка «по расписанию».
- **Где:** вид «День» расписания — строка окна между парами («Окно 1 ч 40 мин · свободны по расписанию: 2029, 3014, 4044 и ещё 12»), как строка перехода между корпусами (`TransitionRow` в `src/components/schedule/day.tsx`); на «Сейчас» — та же строка под плашкой пары, если сейчас окно (до следующей пары ≥ 60 мин и сегодня уже была пара).

## Тесты

- **Интеграция:** `rateRequest` чужой заявки и повторная оценка → отказ; `acceptOffer` неподходящим студентом → отказ; `busyRooms`.
- **e2e:** Алиса — предложение → «Подать заявление» → заявка с «Предложено деканатом» у Ирины; «Не сейчас» прячет; Тимур предложения не видит, поддельный `acceptOffer` (подмена формы) → отказ; оценка готовой заявки → у Ирины средняя и комментарий; Тимур не может оценить заявку Алисы (поддельный номер) → нет изменений; окно со свободными аудиториями в дне расписания; 360px и 200 % без скролла вбок, обе темы, axe.
