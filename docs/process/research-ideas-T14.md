# Ресерч: передовые идеи для «Протокола» (11.11, T14)

> Запрос человека: «Набросай ещё смелых идей, которые можно реализовать для упрощения работы деканата и приятного взаимодействия студентов с ним. Проведи ресерч по похожим сайтам, зарубежным в том числе».
> Делал субагент Claude Code (general-purpose) веб-поиском. **Надёжность:** страницы с «✓» агент открыл и прочитал сам; остальные ссылки — из выдачи поиска (заголовок и фрагмент), целиком не открывались. Почти все зарубежные цифры эффекта — от вендоров (Mainstay, EAB). Исключено всё, что в «Протоколе» уже есть.

## Топ-5 по оценке агента (баллы жюри при наименьшем риске)
1. **«Вам положено»** (M, ~1–1,5 дня) — самая смелая: деканат приходит к студенту сам. Видео: Алиса закрыла долг → на «Сейчас» «Вам доступна повышенная стипендия» → касание → у Ирины заявка с пометкой «предложено деканатом».
2. **Оценка заявки + «Вы сказали — мы сделали»** (S, ~полдня) — двустороннее общение, метрика качества у сотрудника.
3. **«Я заболел»** (M, ~1–1,5 дня) — деканат доверяет студенту на короткий срок.
4. **Электронный студенческий с QR** (S–M, ~1 день) — повестка 539-ФЗ; переиспользует страницу проверки.
5. **«Свободные аудитории сейчас»** (S, ~полдня) — «хочется пользоваться каждый день».

## На будущее (видение для отчёта)
- Справки и диплом как verifiable credentials (Europass EDC / EBSI) + ссылка со сроком (My eQuals) — следующая ступень после нашего QR.
- Проактивный деканат на ранних сигналах (Navigate360, Georgia State) поверх электронных зачёток по 539-ФЗ; «Как ты?» — только с человеком на эскалации и отдельным согласием.
- Жизненные ситуации как суперсервисы (Госуслуги, Эстония): «Еду по обмену», «Академический отпуск» вместо набора бланков.

**Вывод про уведомления:** исследования (J-PAL/NBER, EEF) показывают, что массовые напоминания теряют эффект. Поэтому «Протокол» делает уведомления персональными и с действием, а не увеличивает их число.
