## 3. Проверка перед отправкой (5 минут)

- [ ] Прототип открывается **с телефона без VPN**, внизу и на входе видна плашка «Концепт для конкурса…».
- [ ] Вход **по логину и паролю** работает для всех четырёх аккаунтов — каждый пароль проверить на проде, а не по памяти (пароли прода могут отличаться от локальных).
- [ ] Видео открывается по ссылке **в окне инкогнито** (без входа в Яндекс). На Яндекс Диске сейчас висит плашка «Продолжаем восстанавливать Диск» — надёжнее добавить **вторую ссылку** (VK Видео или RuTube) и вписать её в комментарий рядом.
- [ ] PDF открывается и весит меньше лимита формы (если форма не берёт ~4,7 МБ — дать ссылку на GitHub из таблицы выше).
- [ ] Ссылка на GitHub открывается в инкогнито (репозиторий публичный).
