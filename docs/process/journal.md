**Что сделал ИИ:**
- **Зависимости:** `@react-pdf/renderer@4.9.0` и `uqr@0.1.3` через `pnpm add -E` — `minimumReleaseAge` и `trustPolicy` пропустили без обходов, `pnpm audit --prod` — 0. - **PDF** (`/requests/[number]/pdf`, route handler): только владелец — `WHERE number AND studentId = ctx AND «Готова/Выдана» AND документ не отозван`, иначе 404 без тела; генерация по запросу, файлы не храним. Английская справка — ФИО по ICAO 9303 (как в загранпаспорте), факультеты по-английски. Без номера зачётки и оценок.
