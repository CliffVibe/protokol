---
description: Взять следующую задачу из плана и подготовить план реализации
---
1. Открой `docs/tasks/README.md`, найди первую задачу со статусом ☐ (или задачу $ARGUMENTS, если указана).
2. Прочитай файл задачи и документы, на которые он ссылается (всегда — CLAUDE.md; по теме — 03/04/05).
3. Если что-то неясно — задай вопросы одним списком и остановись.
4. Иначе предложи план: файлы, которые создашь/изменишь; тесты; какие субагенты вызовешь в конце; риски. Жди одобрения.
5. После одобрения — реализуй, прогони проверки из «Определения готово», поставь ◐ в README, по завершении ☑.
